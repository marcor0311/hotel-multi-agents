# Servicio de protección mediante A2A

Resolver proveedor autorizado y verificar endpoint/identidad/auth. Enviar solo ventana, zona amplia, pasajeros y referencia opaca. Validar respuesta/cotización y vigencia, presentarla al huésped; tras autorización explícita, tramitar pago simulado y confirmación A2A. Errores o identidad no verificada: no reservar; escalar a recepción. No se implementa protección física real.
