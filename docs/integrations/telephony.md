# Telefonía

El adaptador de voz es un límite de integración pendiente de proveedor. Caller ID o extensión puede ayudar a resolver contexto si la central lo valida, pero no autentica operaciones sensibles. La transferencia a recepción solo se anunciará cuando exista capacidad de transferencia confirmada. Sin ella, registrar/indicar asistencia de front desk sin simular conexión.
