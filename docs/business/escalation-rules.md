# Reglas de escalamiento

Escalar identidad ambigua, estancia inactiva, situación de salud/seguridad delicada, solicitud fuera de política, falla de sensor, discrepancia financiera, proveedor no verificado, error repetido o petición explícita de hablar con una persona. Registrar solo información mínima. Si no hay transferencia, informar que recepción está disponible y que la conversación aún no fue conectada.
